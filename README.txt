HEALING SOULS — PEVONIA PRODUCT FINDER (installable web app / PWA)

WHAT'S IN HERE
  index.html ............. the app (open this / it's the homepage)
  manifest.webmanifest ... makes it installable with name + icons
  sw.js .................. offline support (works with no signal)
  icon-192.png / icon-512.png / icon-512-maskable.png / apple-touch-icon.png ... home-screen icons

PUT IT ONLINE (GitHub Pages)
  1. Create a new repo (e.g. pevonia-finder).
  2. Upload ALL the files in this folder to the repo root (keep the names exactly).
  3. Settings > Pages > Source: main branch, root. Save.
  4. Wait ~1 minute for the live link, then text that link to staff.

INSTALL ON A PHONE
  iPhone (Safari): Share > Add to Home Screen.
  Android (Chrome): menu > Install app / Add to Home screen.
  It launches full-screen with the Healing Souls icon and works offline.

WHAT IT COVERS
  117 Pevonia products: all facial lines PLUS body, de-aging body, foot,
  chocolate, sun, bathing, hair, and Spalasium massage oils.
  Tabs: Products | Services | Order | Why | Ingredients
  Services groups products by treatment type (facial, body wrap, scrub,
  foot, massage, etc). Step-by-step Pevonia protocols can be added later
  once requested from the rep (marketing@pevonia.com).

UPDATING LATER
